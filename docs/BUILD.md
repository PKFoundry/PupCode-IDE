# Build Guide

## Supported Runtimes and Tools

| Component | Minimum Version | How to Verify |
|-----------|----------------|---------------|
| Rust toolchain | 1.75+ | `rustc --version` |
| Node.js | 18+ | `node --version` |
| npm | 9+ | `npm --version` |
| Python | 3.13+ | `python3 --version` |
| pip | 24+ | `pip --version` |

### Platform-Specific SDKs

| Platform | Required Packages |
|----------|-------------------|
| **macOS** | Xcode Command Line Tools (`xcode-select --install`), Apple Silicon or Intel matching Rust target |
| **Windows** | Visual Studio Build Tools (C++ workload), MSVC compiler |
| **Linux** | `build-essential`, `libssl-dev`, `pkg-config`, `libgtk-3-dev`, `libwebkit2gtk-4.1-dev` (Ubuntu/Debian); equivalent packages for other distros |

## Dependency Installation

### 1. Rust Dependencies

```bash
cargo build
```

Cargo resolves dependencies declared in `Cargo.toml`. Key runtime dependencies include `tauri`, `tokio`, `reqwest`, `serde`, `rand`, and `libc`.

### 2. Node.js Dependencies

```bash
npm install
```

Installs frontend and build dependencies from `package.json`. Key dependencies include:
- `react` / `react-dom` — UI framework
- `zustand` — state management
- `monaco-editor/react` — code editor
- `lucide-react` — icon set
- `tailwindcss` — CSS framework
- `@tauri-apps/api` — Tauri IPC bridge

### 3. Python Dependencies (External)

The sidecar runs within an **externally-managed Python 3.13+ environment** where `code-puppy` is already installed. The sidecar's own requirements are minimal:

```txt
fastapi>=0.136
uvicorn[standard]>=0.48
websockets>=16.0
pydantic>=2.13
watchdog>=6.0
```

These are declared in `sidecar-src/requirements.txt` and should be available in the same Python environment that hosts `code-puppy`. Install with:

```bash
pip install -r sidecar-src/requirements.txt
```

> **Note:** The sidecar discovers Python at runtime through the Rust sidecar manager (`src/sidecar.rs`). It searches standard paths on each platform. Ensure `python3` (or `python`) resolves to the correct interpreter with `code-puppy` installed.

## Development Builds

### Dual-Server Dev Mode

The recommended development workflow runs the Tauri backend and Vite frontend concurrently:

```bash
npm run tauri dev
```

This starts:
1. The Rust Tauri development process (hot-reloads Rust code)
2. A Vite dev server for the React frontend (hot-module replacement)

The Tauri window opens automatically and connects both layers.

### Frontend-Only Dev

To develop the React frontend independently:

```bash
npm run dev
```

This starts only the Vite dev server. The frontend will attempt to connect to a running sidecar.

### Rust-Only Build

```bash
cargo build --release
```

Produces a release binary in `target/release/`. This includes the embedded React frontend (bundled separately — see below).

## Production Builds

### Full Production Bundle

```bash
npm run tauri build
```

This:
1. Bundles the React frontend with Vite (`vite build`)
2. Compiles the Rust shell in release mode
3. Packages everything into a platform-native installer:
   - **macOS**: `.dmg` and `.app`
   - **Windows**: `.msi` and `.exe` (NSIS)
   - **Linux**: `.AppImage`, `.deb`, `.rpm`

Output location: `src-tauri/target/release/bundle/`

### Standalone Frontend Build

```bash
npm run build
```

Produces a static frontend bundle in `dist/` suitable for embedding in the Tauri application.

## Environment Variables

| Variable | Used By | Description |
|----------|---------|-------------|
| `SIDECAR_AUTH_TOKEN` | Sidecar (at runtime) | Auth token for HTTP/WebSocket requests. Generated by the Rust sidecar at startup. |
| `SIDECAR_PORT` | Sidecar (at runtime) | Randomized port assigned by the Rust sidecar manager. |
| `SIDECAR_WORKING_DIR` | Sidecar (at runtime) | Working directory passed to the Python process at startup. |

These are set programmatically by the Rust sidecar manager and are not typically configured manually.

## CI-Equivalent Commands

To reproduce the full CI validation locally:

```bash
# 1. Install dependencies
npm install
cargo build

# 2. Build the release binary
npm run tauri build

# 3. Run Python tests
python3 -m pytest tests/ -v
```

## Common Build Failures

| Symptom | Cause | Fix |
|---------|-------|-----|
| `error[E0463]: can't find target lib...` | Missing platform SDK (e.g., WebKit2GTK on Linux) | Install the required system packages listed above |
| `python3: command not found` in sidecar | Python not in PATH or wrong version | Ensure Python 3.13+ is on PATH |
| `ModuleNotFoundError: code_puppy` | code-puppy not installed in the discovered Python | Install code-puppy in the correct Python environment |
| Vite build fails with CSS errors | Tailwind PostCSS misconfiguration | Verify `postcss.config.mjs` references `tailwind.config.js` correctly |
| Tauri capabilities error | Invalid permissions JSON | Validate `capabilities/default.json` against Tauri v2 schema |
| Sidecar spawn fails on first run | No free port or leftover zombie process | Kill any orphaned Python sidecars: `pkill -f sidecar_main.py` |

## Generated Assets

| Artifact | Location | Produced By |
|----------|----------|-------------|
| Frontend static bundle | `dist/` | `vite build` |
| Tauri release binary | `src-tauri/target/release/` | `cargo build --release` |
| Platform installers | `src-tauri/target/release/bundle/` | `tauri build` |
| Sidecar SQLite DB | `~/.pupcode_ide/session_db.sqlite` | Runtime (first launch) |
| Session autosaves | code-puppy's `AUTOSAVE_DIR` | code-puppy runtime |
| Voice config | `~/.pupcode_ide/voice.json` | Runtime (voice settings) |
| Custom themes | `~/.pupcode_ide/themes/` | Runtime (theme manager) |
